# Quilled

A letter written with an Apple Pencil, a finger, or the keyboard.

Pencil, fountain, and a fixed italic nib. Pressure and tilt come from the pencil. Turn on Finger and a finger draws. Turn on Type, tap the page, and the keys write. Stain lets a wet finger smear.

Invite someone with the link or the QR code. They join the same desk and see the stroke as it is made. The letter stays in the browser. It is not stored in Subversion.

Drawing uses [open-quill](https://github.com/qiqstart/open-quill).
